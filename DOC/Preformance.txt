1.Server-side Pagination + Cursor-based

  - A = คงเหลือ
  - B = MIN
  - C = ถัวเฉลี่ย/วัน × ระยะเวลาส่ง(วัน)

  สถานะ:

  1. A ≤ B และ A ≤ C → ต้องสั่งซื้อ
  2. A > B แต่ A ≤ C → ต้องสั่งซื้อ
  3. A ≤ B แต่ A > C → ต้องสั่งซื้อ
  4. A > B และ A > C → ปกติ

  สรุปสั้น: ต้องสั่งซื้อถ้า A ≤ B หรือ A ≤ C (ถ้าผ่านทั้งสองถึงจะปกติ)
