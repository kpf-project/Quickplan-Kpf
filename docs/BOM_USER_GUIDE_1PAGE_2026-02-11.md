# คู่มือหน้างาน: ผูกสูตร BOM + วางแผนการผลิต (ฉบับสั้น)
อัปเดต: 2026-02-11

เอกสารนี้สำหรับผู้ใช้งานหน้างาน ใช้อ่านเร็วและทำตามได้ทันที

## 1) ก่อนเริ่ม: ต้องรู้อะไรบ้าง

ให้เตรียมข้อมูล 2 อย่างนี้ก่อน
1. `base_batch` = จำนวน Batch ตั้งต้นของสูตร
2. `base_output_boxes` = จำนวนลังที่ได้จาก Batch ตั้งต้นนั้น

ตัวอย่าง:
- 16 Batch ได้ 280 ลัง
- กรอก `base_batch = 16`
- กรอก `base_output_boxes = 280`

ระบบจะคำนวณให้อัตโนมัติว่า
- `1 Batch = 17.5 ลัง`

## 2) วิธีกรอกหน้า BOM (ไลน์การผลิต)

### ส่วนหัวสูตร
1. ใส่ Batch ตั้งต้น (`base_batch`)
2. ใส่จำนวนลังตั้งต้น (`base_output_boxes`)
3. ดูค่าที่ระบบคำนวณอัตโนมัติ `1 Batch = ... ลัง`

### ส่วนรายการวัตถุดิบ/WIP
- ใส่รายการ Child และจำนวนที่ใช้
- จำนวนที่ใส่ คือ "ปริมาณสำหรับฐานสูตรที่กรอกไว้" (ไม่ใช่ต่อ 1 ลัง)

ตัวอย่าง:
- ถ้าหัวสูตรเป็น 16 Batch / 280 ลัง
- จำนวนวัตถุดิบด้านล่างทั้งหมด หมายถึงใช้สำหรับ 16 Batch

## 3) กติกาการผูก (สำคัญ)

- FG (04, 04-1, 04-2) ใส่ Child ได้: WIP หรือ RAW
- WIP (03) ใส่ Child ได้: RAW เท่านั้น
- RAW (01, 02, 05, 08, 10) ห้ามเป็น Parent

ถ้าผิดกติกา ระบบจะไม่ให้บันทึก

## 4) วิธีใช้หน้า Planning

1. เลือกสูตร BOM ที่ผูกไว้
2. กรอก Batch ที่ต้องการผลิตจริง
3. ระบบคำนวณให้อัตโนมัติจากฐานสูตร

หลักการคำนวณ:
- `scale = batch ที่จะผลิต / base_batch`
- ทุกรายการในสูตรจะถูกคูณด้วย scale

ตัวอย่าง:
- สูตรตั้งต้น 16 Batch
- ถ้าจะผลิต 8 Batch
- ระบบจะใช้วัตถุดิบครึ่งหนึ่งของสูตรตั้งต้น

## 5) กรอกผ่าน Excel (สรุปเร็ว)

คอลัมน์ที่ต้องใช้จริง:
- A รหัสสินค้า
- C base_batch
- D base_output_boxes
- E รหัสวัตถุดิบ/WIP
- G จำนวน
- H หมายเหตุ

ระบบ Import จะอ่านเฉพาะคอลัมน์: `A/C/D/E/G/H`

หมายเหตุ:
- B/F เป็นชื่อที่ระบบเติมให้เองจากรหัส (ห้ามแก้)
- คอลัมน์ J เป็นช่องค้นหา WIP/RAW
- K/L/M แสดงผลค้นหา (รหัส/ชื่อ/หน่วย)

## 6) เช็กลิสต์ก่อนกดบันทึก/นำเข้า

1. ใส่ `base_batch` และ `base_output_boxes` แล้ว
2. Parent/Child ไม่ผิดกติกา FG/WIP/RAW
3. จำนวนวัตถุดิบเป็นปริมาณตามฐานสูตรเดียวกัน
4. ไม่มีการใช้รูปแบบเก่า `base_boxes`

## 7) ถ้าเจอปัญหา

- บันทึกไม่ได้เพราะ Matrix: ตรวจว่าประเภท Parent/Child ถูกกติกาหรือไม่
- Import ไม่เข้า: ตรวจคอลัมน์ให้ตรง `A/C/D/E/G/H`
- ค้นหาใน Excel ไม่ขึ้น: ใช้ไฟล์ export ล่าสุดจากระบบก่อน
