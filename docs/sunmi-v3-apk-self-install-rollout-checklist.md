# SUNMI V3 ติดตั้งผ่านลิงก์ APK (ไม่ใช้ MDM)

อัปเดต: `2026-02-19`
เป้าหมาย: ให้ทีมหน้างานติดตั้งแอป `Sunmi Wrapper` เองจากลิงก์/QR ได้ง่าย และอัปเดตทับเวอร์ชันเดิมได้

## 1) เตรียมไฟล์ที่เครื่อง Dev (ทำครั้งเดียวต่อ 1 เวอร์ชัน)

1. เปิดโปรเจกต์ `android/sunmi-v3-wrapper` ใน Android Studio
2. ไปที่ `Build > Generate Signed Bundle / APK...`
3. เลือก `APK`
4. เลือก keystore เดิมของโปรเจกต์ (ห้ามเปลี่ยน keystore)
5. เลือก `release`
6. Build ให้สำเร็จ และได้ไฟล์ `app-release.apk`
7. เปลี่ยนชื่อไฟล์ให้ชัดเจน เช่น `kpf-sunmi-wrapper-1.0.1.apk`
8. อัปโหลดไฟล์ขึ้น URL ที่เป็น `https://` เท่านั้น
9. สร้าง QR จาก URL ไฟล์ APK

## 2) กติกาเวอร์ชันก่อนปล่อย

1. `applicationId` ต้องเดิม: `com.kpf.productionline.sunmiwrapper`
2. ต้องเซ็นด้วย keystore เดิมทุกครั้ง
3. ต้องเพิ่ม `versionCode` ทุกครั้งก่อนปล่อยเวอร์ชันใหม่
4. `versionName` เพิ่มตามที่ทีมต้องการสื่อสาร

## 3) ขั้นตอนที่เครื่อง SUNMI (ทีละเครื่อง)

1. ต่อ Wi-Fi/อินเทอร์เน็ตให้พร้อม
2. เปิดสิทธิ์ `Install unknown apps` ให้แอปที่ใช้โหลดไฟล์ (Browser หรือ File Manager)
3. เปิดลิงก์ APK หรือสแกน QR
4. ดาวน์โหลดไฟล์ APK ให้ครบ
5. กด `Install`
6. ถ้ามีแอปเดิมอยู่ ให้กดยืนยัน `Update` (ติดตั้งทับ)
7. เปิดแอป `Sunmi Wrapper`
8. ล็อกอินและเข้า `Daily Work`
9. ทดสอบ 1 รายการ: สแกน QR -> บันทึก -> พิมพ์

## 4) เกณฑ์ผ่านหลังติดตั้ง

1. เปิดแอปได้ปกติ
2. เข้า Daily Work ได้
3. กดพิมพ์แล้วไม่เด้ง dialog เลือกเครื่องพิมพ์
4. พิมพ์ออกเครื่อง SUNMI ทันที
5. ข้อมูลบนใบพิมพ์ครบ: ประเภทงาน, รหัส-ชื่อ, จำนวน/หน่วย, เวลา, วันที่

## 5) ปัญหาที่พบบ่อยและวิธีแก้เร็ว

1. ติดตั้งไม่ผ่าน (`App not installed`)
2. สาเหตุที่เป็นไปได้: keystore ไม่ตรงเวอร์ชันเดิม
3. วิธีแก้: build ใหม่ด้วย keystore เดิม
4. ติดตั้งทับไม่ได้
5. สาเหตุที่เป็นไปได้: `versionCode` ไม่เพิ่ม
6. วิธีแก้: เพิ่ม `versionCode` แล้ว build ใหม่
7. กดลิงก์แล้วติดตั้งไม่ได้
8. สาเหตุที่เป็นไปได้: ยังไม่เปิด `Install unknown apps` หรือ URL ไม่ใช่ `https://`
9. วิธีแก้: เปิดสิทธิ์ให้ Browser/File Manager และใช้ลิงก์ `https://`
