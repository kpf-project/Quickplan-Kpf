# Stock Lot Balance Report Header Design

## Objective

ปรับเฉพาะ Header ภายในกระดาษ A4 ของหน้า `/production-line/stock/balance/lot` ให้ชื่อรายงานอยู่กึ่งกลางกระดาษ แสดงอัตลักษณ์บริษัทตามรูปอ้างอิง และแสดงชื่อผู้พิมพ์จากผู้ใช้ที่เข้าสู่ระบบอย่างถูกต้อง ทั้งหน้าพรีวิวและตอนพิมพ์

## Layout

Header ใช้ Grid สามคอลัมน์แบบ `1fr auto 1fr` เพื่อให้ชื่อรายงานอยู่กึ่งกลางกระดาษจริงโดยไม่ขึ้นกับความกว้างของข้อมูลฝั่งซ้ายหรือขวา

- ซ้าย: โลโก้ KPF ขนาดเดิม และชื่อบริษัทสองบรรทัด
  - `บริษัท เคพีฟู้ดส์ จำกัด`
  - `K.P. foods Co.,Ltd.`
- กลาง: `รายงานสรุปยอดคงเหลือสินค้าแยกตาม Lot`
- ขวา: หน่วยงาน วันที่พิมพ์ และผู้พิมพ์ โดยจัดชิดขวาตามรูปแบบรายงานเดิม

ชื่อรายงานต้องไม่อยู่รวมกับกลุ่มโลโก้และชื่อบริษัทอีกต่อไป และ Header ต้องไม่ทับกันบนกระดาษ A4 แนวตั้ง

## User Data

ข้อมูลจาก `useUserProfile()` มีฟิลด์ `username`, `department`, และ `loaded` แต่ไม่มีฟิลด์ `name` สาเหตุที่รายงานแสดงผู้พิมพ์เป็น `-` คือคอมโพเนนต์อ้าง `profile.name`

รายงานนี้จะใช้ `profile.username` เป็นชื่อผู้พิมพ์ทั้งหน้าพรีวิวและตอนพิมพ์ หากข้อมูลยังไม่มีหรือโหลดไม่สำเร็จจึงแสดง `-` ตาม fallback เดิม

## Rendering Scope

แก้เฉพาะ `ProductionStockLotBalanceReportPageClient.js` ใน Header สองชุด:

1. Header ของหน้าพรีวิวกระดาษ A4
2. Header ของทุกหน้าที่สร้างไว้สำหรับคำสั่งพิมพ์

ไม่เปลี่ยนตาราง สูตรคำนวณ การแบ่งหน้า ตัวกรอง ปุ่ม เมนู สีเนื้อหารายงาน หรือหน้าอื่น

## Verification

เพิ่ม regression test เพื่อตรวจว่า:

- Header ใช้ Grid สามคอลัมน์ทั้งพรีวิวและตอนพิมพ์
- ชื่อบริษัทภาษาไทยและอังกฤษปรากฏครบทั้งสองโหมด
- ชื่อรายงานอยู่ในคอลัมน์กลาง
- ผู้พิมพ์ใช้ `profile.username` และไม่มีการอ้าง `profile.name`
- การทดสอบเดิมของรายงานยังผ่าน และ ESLint ไม่มีข้อผิดพลาด
