# ออกแบบการแยกเมนูรายงานคงเหลือราย Lot

## เป้าหมาย

แยกรายงานคงเหลือราย Lot ออกเป็นสองปลายทางที่เลือกได้จากเมนูรายงานโดยตรง และทำให้หน้า A4 แสดงเป็นกระดาษแนวตั้งที่ชัดเจนโดยไม่มีกรอบแผงรายงานซ้อนอยู่รอบกระดาษ

## โครงสร้างเมนู

เปลี่ยนรายการตรง `รายงานสรุปคงเหลือราย Lot` ในเมนู `รายงาน` เป็นหมวดเมนูย่อยรูปแบบเดียวกับหมวด `รายงานชั่ง` โดยมีสองรายการ:

1. `รายงานสรุปคงเหลือราย Lot แบบละเอียด` เปิด `/production-line/stock/balance`
2. `รายงานสรุปยอดคงเหลือราย Lot` เปิด `/production-line/stock/balance/lot`

ใช้ `next/link` และกลไก prefetch เดิมของ `WeightScalePrimaryHeader` เพื่อให้การเปลี่ยนหน้าเป็น client-side navigation และเริ่มเตรียม route เมื่อผู้ใช้เปิดหรือชี้เมนู

## หน้าแบบละเอียด

หน้า `/production-line/stock/balance` ยังคงข้อมูล ตัวกรอง ตาราง สรุป และการส่งออก Excel เหมือนเดิมทั้งหมด แต่ถอดปุ่ม `รายงาน A4 แนวตั้ง` ออก เพราะผู้ใช้เข้าหน้า A4 ได้โดยตรงจากเมนูหลักแล้ว

## หน้าสรุปยอดคงเหลือราย Lot แบบ A4

หน้า `/production-line/stock/balance/lot` ยังคงตัวกรอง แถบคำสั่งกลับหน้าเดิม ส่งออก Excel พิมพ์รายงาน และตัวเปลี่ยนหน้ารายงานไว้

บริเวณพรีวิวจะเปลี่ยนดังนี้:

- ถอดกรอบสีน้ำเงิน กล่องสีขาว padding และเงาของ container ชั้นนอกที่ล้อมทั้งส่วนพรีวิว
- แยกแถบข้อมูลจำนวนหน้าและปุ่มคำสั่งให้อยู่เหนือกระดาษ โดยไม่สร้างกรอบล้อมกระดาษ
- ใช้พื้นหลังสีเทาอ่อนเป็นพื้นที่วางกระดาษ
- แสดงกระดาษสีขาวขนาด A4 แนวตั้ง `210mm × 297mm` อยู่กึ่งกลาง
- คงเงารอบกระดาษเพื่อแยกกระดาษออกจากพื้นหลัง
- ไม่เปลี่ยนเนื้อหารายงาน การแบ่งหน้า ตาราง ยอดรวม หรือ CSS สำหรับการพิมพ์
- ใช้ static style block สำหรับ CSS ตารางแทน `styled-jsx` เพื่อให้ server และ client สร้าง attributes ตรงกันและไม่เกิด hydration mismatch

## ขอบเขตและข้อมูล

- ไม่เพิ่ม API หรือ query ใหม่
- ใช้ route และข้อมูล server-side เดิมทั้งสองหน้า
- ไม่เปลี่ยน logic การคำนวณยอดคงเหลือ
- ไม่แตะหน้าชั่งเข้า ชั่งคืน เบิก หรือฐานข้อมูล

## การตรวจสอบ

1. เมนูรายงานแสดงหมวดคงเหลือราย Lot พร้อมสองรายการและเส้นทางถูกต้อง
2. การคลิกแต่ละรายการเปลี่ยนหน้าผ่าน Next.js navigation โดยไม่เกิด full-page reload จากการใช้ anchor ธรรมดา
3. หน้าแบบละเอียดไม่มีปุ่ม `รายงาน A4 แนวตั้ง`
4. หน้า A4 ไม่มีกล่องหรือกรอบล้อมส่วนพรีวิว เหลือกระดาษสีขาวแนวตั้งพร้อมเงา
5. ตัวกรอง Excel การเปลี่ยนหน้าพรีวิว และการพิมพ์ยังทำงานเหมือนเดิม
6. รัน regression test ที่ตรวจโครงสร้างเมนูและรายงาน และรัน ESLint เฉพาะไฟล์ที่แก้
7. หน้า A4 ไม่มี `styled-jsx` scope class ที่ทำให้ server/client attributes ไม่ตรงกัน
